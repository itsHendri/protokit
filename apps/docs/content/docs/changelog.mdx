## October 2026

- **Monorepo.** The kit moved to `apps/mobile` in the [protokit](https://github.com/itsHendri/protokit)
  repository, next to this site. Each app still works on its own when copied out.
- **`@itshendri/kit-tokens`.** The token build is a package: one `tokens.json` to NativeWind, Tailwind 4 /
  shadcn, TypeScript, Figma and `DESIGN.md`, with the WCAG AA gate.
- **Registry as data.** One list of components generates `DESIGN_SYSTEM.md`, `llms.txt`, a shadcn registry
  and the component pages here.
- **Embed mode.** The kit's web build can run inside a page (these phone frames) and follows the page's
  theme.
- **Public and MIT licensed.**
